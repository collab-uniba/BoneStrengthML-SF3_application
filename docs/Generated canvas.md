# BoneStrength ML: Machine Learning Canvas

## Value Proposition

BoneStrength ML serves orthopedic clinicians by predicting the efficacy of various interventions to prevent hip fractures in frail elderly patients. This tool empowers physicians to select the most appropriate treatment for each patient, with the ultimate goal of reducing fracture incidence and extending the time before fractures occur when they cannot be prevented entirely.

In the initial implementation, the system will operate using a batch processing workflow: clinicians submit CT scans, the inference pipeline processes these images at the laboratory, and data scientists prepare comprehensive reports detailing intervention efficacy. While real-time results are the long-term objective, this phased approach allows for immediate clinical utility.

## Prediction Task

BoneStrength ML performs a regression task that predicts bone strain values based on patient-specific femur characteristics. The model takes inputs derived from CT scans, including:
- 93 principal components (PCs) from the morpho-densitometric femur statistical atlas
- PosAnt and MedLat angles describing impact force orientation during side-fall events

The model outputs two critical strain measurements:
- max_Strain_11: maximum first principal strain from finite-element simulation
- max_Strain_33: minimum third principal strain from finite-element simulation

These strain values determine whether a fracture would occur under specific fall conditions.

## Decisions

The strain predictions are translated into actionable clinical information through comprehensive reports that quantify the expected efficacy of various therapeutic interventions. These reports provide clinicians with the evidence needed to make informed treatment decisions, enabling personalized care that optimizes fracture prevention outcomes.

## Impact Simulation

As a surrogate model of BoneStrength (the original biophysical model), performance assessment will utilize synthetic data generated by the validated biophysical model. This approach provides a reliable ground truth for evaluation since BoneStrength has been rigorously validated for accuracy.

Performance metrics will include:
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Maximum error (infinity norm)
- Coefficient of determination (R²)

To ensure fairness, synthetic test data will cover diverse demographic groups and real-world scenarios, preventing systematic advantages or disadvantages across different patient populations. The model's risk profile will be thoroughly assessed based on these performance metrics before deployment.

## Making Predictions

While the ultimate goal is real-time clinical prediction, the initial version will implement a batch inference strategy. CT scans submitted by clinicians will be processed in batches to generate comprehensive reports without strict time constraints.

In future iterations, when near-real-time inference becomes essential, the entire prediction workflow—from CT scan to final report—will be optimized to complete within three minutes. Computationally, the inference pipeline will run on proprietary cloud infrastructure, with a client application installed on clinicians' workstations at healthcare facilities.

## Data Collection

The training dataset will consist entirely of synthetic data generated by the original BoneStrength biophysical model. This approach ensures complete coverage of clinically relevant scenarios while maintaining perfect ground truth labels.

BoneStrength ML will only require updates if the underlying biophysical model changes. In such cases, new synthetic training data will be generated from the updated BoneStrength model. Additionally, data from production environments will be systematically collected and periodically evaluated to enhance future training and testing datasets.

## Data Sources

All training data will be derived synthetically from the BoneStrength biophysical model, which provides complete control over data generation and ensures coverage of all relevant clinical scenarios. This synthetic approach eliminates many data acquisition challenges associated with real-world clinical data.

## Building Models

The production environment requires only a single instance of BoneStrength ML. Model updates will be infrequent and only triggered when the underlying BoneStrength biophysical model is updated. Since updates are expected to be rare, there are no strict time constraints on the training process for model updates.

## Features

To utilize the model, the following features must be extracted from patient CT scans:
- 93 principal components representing the morpho-densitometric properties of the femur statistical atlas
- PosAnt and MedLat angles that describe the orientation of impact forces during a side-fall event

These features capture the essential biomechanical characteristics needed for accurate strain prediction.

## Monitoring

The model's predictions will always be reviewed by trained clinicians who can identify potential issues. Any suspicious behavior will trigger comprehensive reliability assessments.

To prevent data drift, input features from production environments will be continuously compared with the original training data distribution. If production data is ever incorporated into model training, periodic validation against the original BoneStrength biophysical model will ensure continued accuracy.

System-level monitoring will track availability, performance, and security threats. Beyond technical metrics, clinical key performance indicators will be tracked longitudinally, including:
- Fracture incidence rates
- Time-to-fracture metrics
- Patient outcomes

This comprehensive monitoring approach ensures that BoneStrength ML continues to deliver its intended clinical value while maintaining technical performance.
